# ADR-004: Изоляция плагинов (Extension Host) и Декларативный UI-протокол GPUI

* **Статус:** Принято
* **Контекст:** Расширяемость CodeContext сторонними модулями (Задача [4] Фазы 4) без деградации холодного старта (`< 10 мс`) и рендеринга GPUI (`120 FPS`).

## Решение
1. **Разделение Декларации и Исполнения (`Lazy Activation`):**
   * Точки расширения (`ContributionPoints`: команды, вкладки `ActivityRail` и `BottomDock`, поставщики контекста, компрессоры кода) описываются декларативно в `plugin.json`.
   * Код плагина запускается только при наступлении подписанного события `ActivationEvent` (`OnPackContext`, `OnCommand`, `OnView`).
2. **Декларативный UI-протокол (`PluginViewSpec`):**
   * Плагины не создают собственных окон ОС и не линкуют `gpui`. Они возвращают дерево `PluginWidgetNode` (`Section`, `Row`, `Column`, `Button`, `Switch`, `Badge`, `CodePreview`), которое нативно рендерится хостом `crates/ui`.
3. **Zero-Trust безопасность (`PluginPermission`):**
   * Доступ к файлам проекта проходит строго через `Sandbox` и `SecretGuard` (файлы секретов `.env*` и приватные ключи никогда не передаются плагинам).
