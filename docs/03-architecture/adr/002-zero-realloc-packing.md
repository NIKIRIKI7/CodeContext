# ADR-002: Двухфазное сканирование и сборка буфера с нулём реаллокаций

* **Статус:** Принято
* **Контекст:** Выполнение критерия успеха (< 1 сек на 4 МБ текста / 50 000 файлов) и отзывчивость UI

## Решение
1. **Разделить работу сканера на две фазы:** `scan_project_index` (быстрый параллельный сбор метаданных `ScannedFile` через батчи в `mpsc`-канале) и потоковую вычитку контента.
2. **Точная преаллокация (`String::with_capacity`):** Итоговый размер буфера рассчитывается до единого байта через `calculate_exact_capacity`.
3. **Потоковая трансформация (`append_transformed_content`):** Минификация и AVX2-нормализация `CRLF -> LF` (`memchr_iter`) пишут напрямую в выходной `&mut String` с **0 промежуточных аллокаций**.
