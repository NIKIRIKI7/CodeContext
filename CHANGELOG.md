# Changelog

Все значимые изменения проекта **CodeContext** документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [0.1.0] - 2026-11-01

### Добавлено
- **Модуль A (`packing`)**: двухфазное параллельное сканирование с учётом `.gitignore`, защитой `SecretGuard`, детекцией бинарных файлов по 8 КБ пробе и сборкой буфера с 0 реаллокаций (`dhat`).
- **Модуль B (`applying`)**: цепочка парсеров (`Canonical`, `Markdown`, `Search/Replace`, `Unified Diff`), детерминированный `Autofix`, песочница путей `Sandbox` и транзакционное применение с откатом `Undo` (`.ctxpack/backups`).
- **Интеграция с ОС (`platform`)**: единое каскадное контекстное меню `CodeContext` с выпадающим списком из 3 действий (`Скопировать (с .gitignore)`, `Применить патч (автофикс)`, `Открыть в GUI`), глобальные хоткеи и Single-Instance IPC.
- **Графический интерфейс (`ui`)**: виртуализированное дерево файлов и просмотрщик многомегабайтного текста на `gpui` (120 FPS).
