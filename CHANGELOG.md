# История изменений (Changelog)

Все значимые изменения проекта **CodeContext** документируются в этом файле (синхронно с английской версией в [`CHANGELOG.en.md`](./CHANGELOG.en.md)).
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

> **Автоматическая генерация:** Для автоматического обновления обоих файлов (`CHANGELOG.md` и `CHANGELOG.en.md`) по истории коммитов Git используйте команду `just changelog <версия>` (или `just tag-release <версия>`).

## [0.2.5] - 2026-11-06

### Добавлено (Added)
- **Командная палитра в стиле Zed (`Ctrl+P` / `Ctrl+Shift+P`, `crates/ui`)**: единый минималистичный оверлей для мгновенного поиска по файлам проекта (переключение чекбокса по `Space`, переход к превью по `Enter`) и вызова команд приложения (`> copy`, `> apply`, `> undo`, `> terminal`, `> theme`, `> clean`, `> rename`).
- **Переименование и перемещение файлов (`=== RENAME FILE: old -> new ===`, `crates/core`, `crates/apply`, `crates/ui`)**: поддержка директив переименования от ИИ с двойной проверкой `Sandbox`, транзакционным откатом в `BackupManifest` и возможностью переименования файлов из UI.
- **Точечное применение и ручное редактирование в `DiffView` (`crates/ui`, `crates/di`)**: кнопки `Применить файл` (поштучная запись одного файла из плана) и `Редактировать` (переключение между diff и буфером кода с возможностью правки и принудительной вставки).
- **Наглядная диагностика конфликтов `SEARCH / REPLACE` (`crates/apply`, `crates/ui`)**: при `SearchBlockConflict` в окне Diff подсвечиваются ненайденный блок `SEARCH` и наиболее похожий участок целевого файла (по коэффициенту биграмм Сёренсена — Дайса) с кнопками `Принудительно применить` и `Скопировать блок`.
- **Визуальная история снимков `Undo` (`.ctxpack/backups`, `crates/apply`, `crates/ui`)**: отображение списка последних транзакций бэкапа с количеством файлов и адресным откатом к выбранному снимку.
- **Zero-Trust подтверждение команд ИИ и шаблоны копирования ошибок (`crates/apply`, `crates/ui`)**: распознавание директив `=== RUN: ... ===` с обязательным диалогом подтверждения перед запуском, авто-проверка после патча и кнопка `Скопировать ошибку для ИИ` с настраиваемыми шаблонами в терминале.
- **Поэтапная очистка и обслуживание (`--clean`, `crates/apply`, `crates/app`, `crates/ui`)**: категория настроек «Очистка и кэш» с расчётом объёма бэкапов `.ctxpack/backups`, временных `.tmp`-файлов и сокетов IPC, а также CLI-команда `codecontext --clean [all|backups|tmp]`.

## [0.2.1] - 2026-11-06

### Добавлено (Added)
- **Структурированный конструктор нового промпта (`crates/ui`)**: в модальном окне системных промптов добавлены явные поля выбора категории (`Патчер`, `Архитектура`, `Поведение ИИ`, `Свои`), ввода названия (`Название`) и многострочного текста инструкции (`Содержимое`) с поддержкой вставки из буфера обмена (`Ctrl+V`).
- **Интерактивный ресайз панелей мышью (`crates/ui`)**: добавлено плавное изменение ширины левой и правой панелей (`SplitPane`) в обоих режимах, а также изменение высоты нижней док-панели терминала и логов перетаскиванием верхней границы (кнопка фиксированного переключения высоты удалена).
- **Категоризированное окно настроек в стиле Zed / VS Code (`crates/ui`)**: настройки разделены на 5 категорий в боковой навигации (`Интерфейс`, `Панели и бар`, `Горячие клавиши`, `Безопасность`, `Система и обновления`) для снижения когнитивной нагрузки.

### Исправлено (Fixed)
- **Сохранение фокуса командной строки и полей ввода при нажатии `Space` (`crates/ui`)**: устранена синтетическая активация `on_click` на корневом контейнере окна при нажатии пробела, из-за которой слетало выделение с поля ввода терминала и поиска.
- **Визуальная целостность нижней панели и модальных окон (`crates/ui`)**: убраны лишние разделительные линии и пустые рамки при фильтрации категорий промптов и в нижней статусной полосе.

## [0.2.0] - 2026-11-04

### Добавлено (Added)
- **Папки как полноправные объекты фильтрации (`crates/core`, `crates/scanner`)**: реализован двухуровневый конвейер фильтрации с отсечением поддеревьев сверху вниз (`Top-Down Pruning`: `IncludeSubtree`, `TraverseOnly`, `PruneSubtree`) до системного вызова чтения содержимого каталога.
- **Прозрачный транзит сквозь исключённых предков (`TraverseOnly`)**: поддержка точечного включения глубоких подпапок (например, `crates/core/src`) внутри исключённой родительской ветки (`crates/`) без утечки соседних папок и файлов родителя.
- **JSON-схема `Schema v2` (`crates/config`)**: раздельные секции `filters` (расширения, glob, regex для файлов) и `folder_filters` (`exclude_names`, `exclude_globs`, `only_folders`, `include_regex_folders`, `exclude_regex_folders`, `folder_overrides` с поддержкой как литеральных путей, так и glob-шаблонов вида `**/node_modules`) с автоматической миграцией `v0 -> v1 -> v2`.
- **Модальное окно фильтров, пользовательские шаблоны Regex и JSON-шаблоны в `assets/` (`crates/ui`, `crates/config`, `crates/scanner`, `crates/di`)**: фильтрация по расширениям (`Все файлы`, `Только выбранные`, `Скрыть выбранные`), ручное добавление расширений, папок и пользовательских шаблонов регулярных выражений (`+ Шаблон` с именем и областью действия), мгновенная проверка `is_valid_regex_pattern` и масштабируемые JSON-шаблоны всей конфигурации в `assets/*.json`.
- **Конструктор системных промптов и кастомные хоткеи (`crates/core`, `crates/ui`)**: модульная сборка и переупорядочивание блоков инструкций патчера (`PromptBlockItem`) по категориям (`Патчер`, `Архитектура`, `Поведение ИИ`, `Свои`), а также настройка пользовательских сочетаний клавиш (`KeymapConfig`).
- **Расширенный набор бенчмарков и рецептов `Justfile` (`crates/scanner`, `crates/ui`, `Justfile`)**: добавлены бенчмарки `bench_6c`–`bench_6e` и `bench_7` для матрицы регулярных выражений, расширений и интерактивного поиска по 50 000 файлам, а также полный набор команд тестирования и профилирования в `Justfile`.

### Производительность (Performance)
- **Пересчёт чекбоксов директорий на 50 000 файлах (`Project::set_directory_selected`)**: ускорен в **23.6 раза** (`883 µs → 37.39 µs`, `1.34 Gitem/s`) за счёт бинарного поиска начала поддерева (`partition_point`) вместо линейного обхода.
- **Нечёткий патчер `fuzzy_indent` (`crates/apply`)**: ускорен в **5.8 раза** (`22.54 ms → 3.88 ms`), а число аллокаций кучи сокращено в **947 раз** (`120 267 → 127 allocs`) благодаря без-аллокационному индексу `TrimmedLine` и ленивой нормализации `Option::None`.
- **Конвейер фильтрации и живая валидация Regex (`CompiledFilterPlan`)**: оценка 10 000 путей в `bench_6a` ускорена в **4.45 раза** (`4.16 ms → 894 µs`, `11.18 Mitem/s`, `0 allocs`) за счёт перевода `StackNormalizedPath` на `enum` без зануления 1 КБ стекового буфера и быстрого сопоставления сегментов `**/<folder>`; живая валидация Regex ускорена более чем в **1 000 раз** (`551 µs → 499.6 ns`, `0 allocs`) благодаря пре-валидатору баланса скобок и 8-слотовому `thread_local`-кэшу.
- **Проекция дерева и живой предпросмотр 4 МБ (`FlatTreeProjection`, `PackService`)**: переупаковка 4 МБ в памяти ускорена в **1.82 раза** (`14.25 ms → 7.82 ms`, `539.5 MB/s` пик); потребление памяти при переключении директории на 50k файлах снижено в **6.3 раза** (`11.4 MB → 1.80 MB`), а при поиске по 50k файлам — в **18.9 раза** (`5.55 MB → 299.9 KB`, `2.61 ms`).
- **Валидация путей песочницы (`validate_sandbox_path`)**: ускорена в **1.89 раза** (`5.27 ms → 2.79 ms` на 10 000 путей) и потребляет на **26% меньше памяти** за счёт раннего отсечения `..` до выделения `PathBuf`.

### Исправлено (Fixed)
- **Изоляция `SystemUpdater` и автовосстановление бинарника (`crates/platform`, `crates/app`)**: `SystemUpdater::new_in_memory()` изолирован от реального системного пути `canonical_install_binary_path()`, добавлена проверка сигнатуры заголовка исполняемого файла ОС (`MZ` / `ELF` / `Mach-O`) и автоматическое восстановление повреждённого бинарника из `.old` или `target/release`.
- **Наследование исключений папок внутри `Include`-override (`crates/scanner`)**: правила `exclude_names` (`node_modules`), `exclude_globs` (`**/fixtures`), и `folder_exclude_regex` теперь корректно отсекают дочерние подпапки внутри явно включённой родительской ветки `folder_overrides`.
- - **Снятие выделения по клавише Пробел (`crates/ui`)**: устранено нежелательное снятие чекбоксов с файлов и директорий при нажатии `Space`; клавиша больше не исключает файлы из контекста при просмотре или вводе команд.

## [0.1.2] - 2026-11-02

### Добавлено (Added)
- **Модальное окно горячих клавиш по действиям (`crates/core`, `crates/config`, `crates/ui`)**: настраиваемая таблица `KeymapConfig` для 8 команд приложения с интерактивной перезаписью сочетаний клавиш (включая автоматический маппинг русской раскладки `ЙЦУКЕН -> QWERTY`), сбросом по умолчанию и быстрым вызовом по `Ctrl+K` без конфликта с копированием `Ctrl+Shift+C`.
- **Token Budget Heatmap и режим «Топ 20 ↓» (`crates/ui`)**: градуированная цветовая индикация веса файлов в дереве (`< 15 КБ` — серый, `15–50 КБ` — жёлтый, `> 50 КБ` — оранжево-красный) и переключение дерева в плоский список 20 самых объёмных файлов проекта внутри меню «Фильтры».
- **Навигация по дереву с клавиатуры и прыжок к превью (`crates/ui`)**: перемещение по дереву стрелками `↑`/`↓`, переключение чекбокса по `Space`, сворачивание/разворачивание папок по `←`/`→` и мгновенная прокрутка `Предпросмотра` к заголовку `=== FILE: ... ===` по `Enter` или клику на имя файла (0 аллокаций кучи, бинарный поиск за $O(\log N)$ по `line_offsets`).
- **Меню «Проекты» и каскадное подменю недавних репозиториев (`crates/core`, `crates/config`, `crates/ui`)**: универсальная кнопка `Проекты ▾` с открытием папки (`Ctrl+O`), созданием нового проекта и выпадающим справа при наведении списком недавних проектов (MRU до 8 путей с дедупликацией префиксов `\\?\`).
- **Частичное и поштучное применение патчей (`crates/di`, `crates/ui`)**: минималистичные чекбоксы на вкладках распознанных файлов (конфликт в одном файле больше не блокирует применение остальных) и кнопка применения отдельного файла в шапке `DiffViewComponent`.
- **Устойчивый к автоформатированию матчер (`crates/apply`)**: этап `try_formatter_agnostic_replace` в цепочке патчера, нечувствительный к переносам строк и висячим запятым после `cargo fmt` и `prettier`.

### Исправлено (Fixed)
- **Мастер-чекбокс дерева файлов и минимализм тулбара (`crates/ui`)**: мастер-чекбокс и счётчик выбранных файлов теперь учитывают только доступные для выбора текстовые файлы (игнорируя бинарные файлы и заблокированные секреты), устраняя залипание в состоянии `[-]`; вторичные кнопки сортировки и сворачивания папок перенесены из поисковой строки в меню «Фильтры».
- **Полная локализация JSON (`crates/ui`)**: все пользовательские строки, статусы и подписи вынесены из кода в `crates/ui/assets/locales.json` (`ru` / `en`).
- **Мгновенный `Apply` без фризов UI-потока (`crates/apply`, `crates/ui`)**: устранены повторный прогон парсера и 6-этапного Fuzzy-матчера при нажатии на «Применить», блокировки `.git/index.lock` (`--no-optional-locks` + `CREATE_NO_WINDOW`), избыточные барьеры `FlushFileBuffers` (`sync_all`) и гонка опроса событий в `MainWindowView::render`.
- **Реальное автообновление в `SystemUpdater` (`crates/platform`, `crates/ui`)**: реализованы скачивание и распаковка платформенных релизных артефактов из GitHub Releases с проверкой `SHA256SUMS.txt`, резервное чтение `releases-index.json`, фоновая проверка при старте и перезапуск обновлённого бинарника.
- **Адаптивная вёрстка и фокус поиска (`crates/ui`, `.github/workflows/ci.yml`)**: исправлено обрезание карточек пустого состояния в узких панелях (`flex_row` + `min_w(0)`), снятие фокуса со строки поиска при клике вне поля и сохранение `$PATH` в контейнере `opensuse/tumbleweed` в CI.

## [0.1.1] - 2026-11-02

### Исправлено (Fixed)
- **CLI & Ресурсный предохранитель (`crates/app`, `crates/scanner`)**: вызов `codecontext` из терминала без аргументов больше не запускает автоматическое сканирование `current_dir()`, предотвращая зависание и аномальный жор памяти при запуске из корня диска `C:\` или домашней папки.
- **Потоковая проверка заголовков (`crates/scanner`)**: детектор бинарных файлов проверяет первые 8 КБ через стековый буфер до вычитки тела файла в ОЗУ; расширен список бинарных расширений (презентации, офисные документы, датасеты); файлы сверх лимита размера по умолчанию не включаются в выборку.
- **Вёрстка WarningBanner (`crates/ui`)**: устранено вылезание длинных названий файлов за пределы рамки карточки (умное сокращение путей + строгий Flexbox min-width); кнопка закрытия надёжно зафиксирована.
- **GPUI Focus Trap & Backdrop (`crates/ui`)**: ввод текста в поиск по дереву изолирован и активен только при явном фокусе (`Ctrl+F`); клик по затемнённому фону модальных окон закрывает их без протекания кликов сквозь оверлей; в `SplitPane` добавлены минимальные размеры колонок.
- **CI openSUSE (`.github/workflows/ci.yml`)**: в шаг установки пакетов `zypper` добавлены `bash`, `tar`, `gzip`, устраняя падение экшена тулчейна Rust с кодом 127.
- **Брендинг (`crates/ui`, `assets`)**: внедрена фирменная векторная иконка `UiIcon::AppLogo` в панель навигации `ActivityRail`.

## [0.1.0] - 2026-11-01

### Добавлено (Added)
- **Модуль A (`packing`)**: двухфазное параллельное сканирование (`ignore` + `rayon`) с учётом иерархических `.gitignore`, защитой `SecretGuard` (Сценарий A3), детекцией бинарных файлов по 8 КБ SIMD-пробе (`memchr`), языковой минификацией, разбивкой на тома (`Chunker`) и сборкой буфера с 0 реаллокаций (`dhat`).
- **Модуль B (`applying`)**: цепочка парсеров (`Canonical`, `Markdown`, `Search/Replace`, `Unified Diff`, `Create/Delete`), детерминированный `Autofix`, 6-этапный нечёткий матчер уровня Zed (коэффициент биграмм Сёренсена — Дайса + поддержка `...`), песочница путей `Sandbox` и транзакционное применение с откатом `Undo` (`.ctxpack/backups`).
- **Интеграция с ОС (`platform`)**: единое каскадное контекстное меню `CodeContext` из 3 действий (`Скопировать (с .gitignore)`, `Применить патч (автофикс)`, `Открыть в GUI`) для Windows Explorer (`HKCU`), macOS Finder (`Services`) и Linux (`Dolphin`, `Nemo`, `Nautilus`), глобальные хоткеи и Single-Instance IPC.
- **Графический интерфейс (`ui`)**: виртуализированное дерево на 50 000 файлов и просмотрщик многомегабайтного текста на `gpui` (120 FPS) с мгновенным переключением языков (`RU / EN`) и тем (`Dark / Light`).
- **Мультиплатформенный CI/CD и Автообновление**: сборка с PGO и Fat LTO под Windows (`x64`, `ARM64`), macOS (`Apple Silicon`, `Intel`, `Universal2`), Linux (`x86_64`, `ARM64` — `.deb`, `.rpm`, `.pkg.tar.zst`, `.AppImage`, `.tar.gz`, `.tar.xz`, `.tar.zst`) и проверка совместимости с FreeBSD и дистрибутивами Linux.
