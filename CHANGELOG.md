## [0.1.2] - 2026-11-02

### Добавлено (Added)
- **Модальное окно горячих клавиш по действиям (`crates/core`, `crates/config`, `crates/ui`)**: настраиваемая таблица `KeymapConfig` для 8 команд приложения с интерактивной перезаписью сочетаний клавиш (включая автоматический маппинг русской раскладки `ЙЦУКЕН -> QWERTY`), сбросом по умолчанию и быстрым вызовом по `Ctrl+K` без конфликта с копированием `Ctrl+Shift+C`.
- **Token Budget Heatmap и режим «Топ 20 ↓» (`crates/ui`)**: градуированная цветовая индикация веса файлов в дереве (`< 15 КБ` — серый, `15–50 КБ` — жёлтый, `> 50 КБ` — оранжево-красный) и переключение дерева в плоский список 20 самых объёмных файлов проекта внутри меню «Фильтры».
- **Навигация по дереву с клавиатуры и прыжок к превью (`crates/ui`)**: перемещение по дереву стрелками `↑`/`↓`, переключение чекбокса по `Space`, сворачивание/разворачивание папок по `←`/`→` и мгновенная прокрутка `Предпросмотра` к заголовку `=== FILE: ... ===` по `Enter` или клику на имя файла (0 аллокаций кучи, бинарный поиск за $O(\log N)$ по `line_offsets`).
- **Меню «Проекты» и каскадное подменю недавних репозиториев (`crates/core`, `crates/config`, `crates/ui`)**: универсальная кнопка `Проекты ▾` с открытием папки (`Ctrl+O`), созданием нового проекта и выпадающим справа при наведении списком недавних проектов (MRU до 8 путей с дедупликацией префиксов `\\?\`).
- **Частичное и поштучное применение патчей (`crates/di`, `crates/ui`)**: минималистичные чекбоксы на вкладках распознанных файлов (конфликт в одном файле больше не блокирует применение остальных) и кнопка применения отдельного файла в шапке `DiffViewComponent`.
- **Устойчивый к автоформатированию матчер (`crates/apply`)**: этап `try_formatter_agnostic_replace` в цепочке патчера, нечувствительный к переносам строк и висячим запятым после `cargo fmt` и `prettier`.

### Исправлено (Fixed)
- **Мастер-чекбокс дерева файлов и минимализм тулбара (`crates/ui`)**: мастер-чекбокс и счётчик выбранных файлов теперь учитывают только доступные для выбора текстовые файлы (игнорируя бинарные файлы и заблокированные секреты), устраняя залипание в состоянии `[-]`; вторичные кнопки сортировки и сворачивания папок перенесены из поисковой строки в меню «Фильтры».
- **Полная локализация JSON (`crates/ui`)**: все пользовательские строки, статусы и подписи вынесены из кода в `crates/ui/assets/locales.json` (`ru` / `en`).
- **Мгновенный `Apply` без фризов UI-потока (`crates/apply`, `crates/ui`)**: устранены повторный прогон парсера и 6-этапного Fuzzy-матчера при нажатии на «Применить», блокировки `.git/index.lock` (`--no-optional-locks` + `CREATE_NO_WINDOW`), избыточные барьеры `FlushFileBuffers` (`sync_all`) и гонка опроса событий в `MainWindowView::render`.
- **Реальное автообновление в `SystemUpdater` (`crates/platform`, `crates/ui`)**: реализованы скачивание и распаковка платформенных релизных артефактов из GitHub Releases с проверкой `SHA256SUMS.txt`, резервное чтение `releases-index.json`, фоновая проверка при старте и перезапуск обновлённого бинарника.
- **Адаптивная вёрстка и фокус поиска (`crates/ui`, `.github/workflows/ci.yml`)**: исправлено обрезание карточек пустого состояния в узких панелях (`flex_row` + `min_w(0)`), снятие фокуса со строки поиска при клике вне поля и сохранение `$PATH` в контейнере `opensuse/tumbleweed` в CI.

## [0.1.1] - 2026-11-02

### Исправлено (Fixed)
- **CLI & Ресурсный предохранитель (`crates/app`, `crates/scanner`)**: вызов `codecontext` из терминала без аргументов больше не запускает автоматическое сканирование `current_dir()`, предотвращая зависание и аномальный жор памяти при запуске из корня диска `C:\` или домашней папки.
- **Потоковая проверка заголовков (`crates/scanner`)**: детектор бинарных файлов проверяет первые 8 КБ через стековый буфер до вычитки тела файла в ОЗУ; расширен список бинарных расширений (презентации, офисные документы, датасеты); файлы сверх лимита размера по умолчанию не включаются в выборку.
- **Вёрстка WarningBanner (`crates/ui`)**: устранено вылезание длинных названий файлов за пределы рамки карточки (умное сокращение путей + строгий Flexbox min-width); кнопка закрытия надёжно зафиксирована.
- **GPUI Focus Trap & Backdrop (`crates/ui`)**: ввод текста в поиск по дереву изолирован и активен только при явном фокусе (`Ctrl+F`); клик по затемнённому фону модальных окон закрывает их без протекания кликов сквозь оверлей; в `SplitPane` добавлены минимальные размеры колонок.
- **CI openSUSE (`.github/workflows/ci.yml`)**: в шаг установки пакетов `zypper` добавлены `bash`, `tar`, `gzip`, устраняя падение экшена тулчейна Rust с кодом 127.
- **Брендинг (`crates/ui`, `assets`)**: внедрена фирменная векторная иконка `UiIcon::AppLogo` в панель навигации `ActivityRail`.

## [0.1.0] - 2026-11-01

### Добавлено (Added)
- **Модуль A (`packing`)**: двухфазное параллельное сканирование (`ignore` + `rayon`) с учётом иерархических `.gitignore`, защитой `SecretGuard` (Сценарий A3), детекцией бинарных файлов по 8 КБ SIMD-пробе (`memchr`), языковой минификацией, разбивкой на тома (`Chunker`) и сборкой буфера с 0 реаллокаций (`dhat`).
- **Модуль B (`applying`)**: цепочка парсеров (`Canonical`, `Markdown`, `Search/Replace`, `Unified Diff`, `Create/Delete`), детерминированный `Autofix`, 6-этапный нечёткий матчер уровня Zed (коэффициент биграмм Сёренсена — Дайса + поддержка `...`), песочница путей `Sandbox` и транзакционное применение с откатом `Undo` (`.ctxpack/backups`).
- **Интеграция с ОС (`platform`)**: единое каскадное контекстное меню `CodeContext` из 3 действий (`Скопировать (с .gitignore)`, `Применить патч (автофикс)`, `Открыть в GUI`) для Windows Explorer (`HKCU`), macOS Finder (`Services`) и Linux (`Dolphin`, `Nemo`, `Nautilus`), глобальные хоткеи и Single-Instance IPC.
- **Графический интерфейс (`ui`)**: виртуализированное дерево на 50 000 файлов и просмотрщик многомегабайтного текста на `gpui` (120 FPS) с мгновенным переключением языков (`RU / EN`) и тем (`Dark / Light`).
- **Мультиплатформенный CI/CD и Автообновление**: сборка с PGO и Fat LTO под Windows (`x64`, `ARM64`), macOS (`Apple Silicon`, `Intel`, `Universal2`), Linux (`x86_64`, `ARM64` — `.deb`, `.rpm`, `.pkg.tar.zst`, `.AppImage`, `.tar.gz`, `.tar.xz`, `.tar.zst`) и проверка совместимости с FreeBSD и дистрибутивами Linux.
